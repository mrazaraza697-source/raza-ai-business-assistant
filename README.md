# RAZA TECHNOLOGIES AI — Business Assistant

RAZA TECHNOLOGIES AI is a beginner-friendly business assistant dashboard built as a free, responsive web app prototype. The project focuses on a professional black-and-gold visual style and a simple workflow for business content generation.

## Brand Identity
- Brand name: RAZA TECHNOLOGIES AI
- Tagline: BUILD SMART. THINK BIG.
- Design style: Professional black-and-gold theme
- Layout: Responsive dashboard for desktop and mobile

## Current Status
This project is currently in a prototype stage.

- The main dashboard is built in `index.html`
- The app includes a working local demo post generator
- The current generator is a frontend-only demo and does not use a real AI model yet
- Real AI integration and backend connectivity are not connected yet
- We prefer free, beginner-friendly tools and simple implementation approaches

## Dashboard Structure
The dashboard includes the following sidebar sections:
- Dashboard
- AI Tools
- History
- Settings

## Planned Features
- Social media post generator
- Advertisement copywriter
- Product description generator
- Post history
- Business profile settings
- Free AI integration options where available

## Project Files
- `index.html` — main working dashboard file
- `index-backup.html` — safety backup file; never modify, rename, overwrite, or delete it
- `README.md` — project documentation

## Important Safety Rules
- Do not overwrite, rename, or delete `index-backup.html`
- Do not modify `index.html` unless explicitly requested for a new development task
- Keep API keys and secrets out of frontend HTML
- Prefer free tools and avoid unnecessary paid services
- Test features before moving to the next step

## Current Development Reality
At this stage:
- The app is functioning as a local demo interface
- Content generation is based on local frontend logic
- No real AI API is connected yet
- The project is designed to be expanded gradually with beginner-friendly development steps

## Development Approach
- Start simple and test each feature carefully
- Keep the backup file untouched
- Build features step by step
- Favor free and lightweight tools
- Keep the UI clean, responsive, and beginner-friendly

## Notes
This project is intended to evolve from a working prototype into a real AI-powered business assistant without requiring advanced paid services at the beginning.
